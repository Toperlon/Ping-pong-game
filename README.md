# Ping-pong-game

Пинг-понг на Python. 

Цель игрока выйграть противника забив мяч в его ворота. 
Сделана для того что бы скоротать своё время.

Управление с помощью стрелочек.
⭡ - ВВЕРХ
⭣ - ВНИЗ 

Очки прибавляются вам или боту если шарик попадёт в чьи-либо ворота.

Как запустить
В папке Ping-pong ⭢ dist ⭢ ping-pong.exe

Игра написана на Pygame
